# Namunalar

Belgilar: **[M]** — qoraqalpoqcha tomoni nashr qilingan manbadan (ilmiy maqola, darslik, imlo lug'ati) olingan yoki shu manbalardagi tayyor bo'laklardan tuzilgan; **[Q]** — qoidalar asosida men tuzganman, filolog tekshirmagan. **[Q] namunalarni "oltin standart" deb hisoblama.**

Har namunada: o'zbekcha manba → "yarim tarjima" (tipik xato) → to'g'ri variant → nima o'zgardi.

---

### 1. Ilmiy uslub [M]
- **O'zbekcha:** Ushbu maqolada qoraqalpoq xalq topishmoqlari tilining sintaktik xususiyatlari tahlil qilingan.
- **Xato:** *Ushbu maqolada qaraqalpaq xalq topishmoqları tilining sintaktik xususiyatlari tahlil qilingan.*
- **To'g'ri:** Bul maqalada qaraqalpaq xalıq jumbaqları tiliniń sintaksislik ózgeshelikleri tallanǵan.
- **O'zgarish:** ushbu → bul; maqola → maqala; xalq → xalıq; topishmoq → jumbaq; -ning → -niń; sintaktik → sintaksislik; xususiyat → ózgeshelik; tahlil qilingan → tallanǵan.

### 2. Bag'ishlangan maqola [M]
- **O'zbekcha:** Ushbu maqola qoraqalpoq tilidagi milliy taom nomlarini o'rganishga bag'ishlangan.
- **To'g'ri:** Usı maqala qaraqalpaq tilindegi milliy taǵam atamaların úyreniwge arnalǵan.
- **O'zgarish:** -dagi → -degi (old qator: til); taom → taǵam; nom → atama; o'rganish → úyreniw; bag'ishlangan → arnalǵan.

### 3. Hozirgi holat [M]
- **O'zbekcha:** Bugungi kunda bir qancha sintaktik tahlil turlari mavjud.
- **To'g'ri:** Búgingi kúnde birqansha sintaksislik analiz túrleri bar.

### 4. Davomli zamon [M]
- **O'zbekcha:** Bolalar maktab atrofida xursand o'ynashyapti.
- **Xato (qozoqcha):** *Balalar mekteptiń átirapında kewilli oynap jatır.*
- **To'g'ri:** Balalar mekteptiń átirapında kewilli oynap atır.

### 5. Rivojlanish [M]
- **O'zbekcha:** Qoraqalpoq tili turkiy tillar guruhiga kiradigan til bo'lib, bugungi kunda boyib, rivojlanib bormoqda.
- **To'g'ri:** Qaraqalpaq tili túrkiy tilleriniń toparına kiretuǵın til bolıp, búgingi kúnde bayıp hám rawajlanıp atır.
- **O'zgarish:** -adigan → -atuǵın/-etuǵın (kiretuǵın); -moqda → -ıp atır.

### 6. Lug'at so'zboshisidan [M]
- **O'zbekcha:** Xalq turmushining turli sohalariga oid yangi so'zlar qo'shildi.
- **To'g'ri:** Xalıq turmısınıń túrli tarawlarına baylanıslı jańa sózler qosıldı.

### 7. Imlo qoidasi [M]
- **O'zbekcha:** Lug'atdagi barcha so'zlar kichik harf bilan yoziladi.
- **To'g'ri:** Sózliktegi barlıq sózler kishi hárip penen jazıladı.
- **O'zgarish:** -dagi → -tegi (jarangsiz k dan keyin, old qator); bilan → penen (jarangsiz p dan keyin).

### 8. Kelishik bilan harakat [M]
- **O'zbekcha:** qishloqqa borish, g'o'zalarni sug'orish, qishloqdan qaytish
- **To'g'ri:** awılǵa barıw, ǵawashalardı suwǵarıw, awıldan qaytıw

### 9. Hozirgi zamon ilmiy matni [M]
- **O'zbekcha:** Hozirgi vaqtda folklor asarlari tilini o'rganish katta masala.
- **To'g'ri:** Házirgi waqıtta folklorlıq shıǵarmalardıń tilin úyreniw úlken másele.

### 10. Olmosh [Q]
- **O'zbekcha:** Menga bu kitobni ber.
- **Xato:** *Menga bul kitapnı ber.*
- **To'g'ri:** Maǵan bul kitaptı ber.
- **O'zgarish:** menga → maǵan; -ni → -tı (jarangsiz p dan keyin).

### 11. Jo'nalish [Q]
- **O'zbekcha:** U maktabga bordi.
- **Xato:** *Ol mektepga bardı.*
- **To'g'ri:** Ol mektepke bardı.

### 12. Chiqish kelishigi [Q]
- **O'zbekcha:** Biz kutubxonadan kitob oldik.
- **To'g'ri:** Biz kitapxanadan kitap aldıq.

### 13. Burun tovushidan keyin [M: shakllar Vikipediyadan]
- **Xato:** *kimdiń, kimden* → **To'g'ri:** kimniń, kimnen (lekin: kimdi, kimge, kimde)

## Imlo tuzatish namunalari

### 14. Eski apostrofli imlo [M]
- **Xato:** *Qaraqalpaq tilinin' orfografiyalıq so'zligi*
- **To'g'ri:** Qaraqalpaq tiliniń orfografiyalıq sózligi

### 15. Katta harf `Í` [M]
- **Xato:** *QARAQALPAQ XALIQ JUMBAQLARI*
- **To'g'ri:** QARAQALPAQ XALÍQ JUMBAQLARÍ

### 16. Aralash yozuv [M: v1 skilldan topilgan haqiqiy xato]
- **Xato:** *AI Qaraqalpaq tilinde juwap bergenде* (oxirgi ikki harf kirillcha)
- **To'g'ri:** AI Qaraqalpaq tilinde juwap bergende

### 17. Korpusdagi shovqin [M: Dilmash korpusining o'z README namunasidan]
- **Korpusda:** *Pedagogikalıq ideal balaǵa ıktıyatlılıq penen katnasta bolıw principine bárqulla ... súyeniwdi talan etedi.*
- **To'g'ri bo'lishi kerak:** ... ıqtıyatlılıq penen qatnasta ... talap etedi.
- **Xulosa:** ochiq korpuslarda ham `k`/`q` adashishi va OCR xatolari bor. Korpus gapini namuna sifatida ko'chirishdan oldin skript bilan tekshir.
