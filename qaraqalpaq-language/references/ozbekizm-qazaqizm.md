# O'zbekizm va qozoqizmlarni oldini olish

Qoraqalpoq tili qipchoq guruhiga kiradi, qozoq va no'g'oy tillariga eng yaqin; o'zbek tilidan esa ko'p so'z va ba'zi grammatik xususiyatlar olgan (Wikipedia, Omniglot). Shuning uchun xatolar ikki tomondan keladi: o'zbekchadan (so'z, qo'shimcha) va qozoqchadan (harf, shakl).

Har bir qoraqalpoqcha shakl manbada uchragan: **[L]** 2020 imlo lug'ati, **[W]** Qoraqalpoq Vikipediyasi, **[D]** darsliklar, **[T]** 2025–2026 ilmiy maqolalar. Jadvaldagi o'zbekcha tomoni — taqqoslash uchun.

## A. Muntazam tovush mosliklari

Bular **tendensiya**, mexanik qoida emas. Har so'zni alohida tekshir.

| O'zbekcha | Qoraqalpoqcha | Misollar |
|---|---|---|
| so'z boshidagi `y-` | `j-` | yo'l → jol; yer → jer; yil → jıl; yaxshi → jaqsı [L] |
| `sh` (ko'p o'z so'zlarda) | `s` | bosh → bas; ish → is; qish → qıs [L] |
| `ch` | `sh` | uch → úsh; kuch → kúsh [L] |
| `-moq` | `-ıw/-iw/-w` | yozmoq → jazıw; o'qimoq → oqıw [L] |
| eski o'zlashmada `x` | `q` | dehqon → diyqan; fuqaro → puqara; ruxsat → ruqsat [L] |
| eski o'zlashmada `f` | `p` | fan → pán [L][D] |
| `o` (ko'p so'zda) | `a` | bola → bala; bor → bar; yo'q → joq [W][L] |
| `v` (o'z so'zlarda) | `w` | suv → suw; tog' → taw [L] |

**Eng ko'p uchraydigan "yarim tarjima"**: o'zbekcha gap qoldirilib, faqat ayrim so'zlar almashtiriladi. Masalan, *"Bu maqolada qaraqalpaq tilining sintaktik xususiyatlari tahlil qilingan"* — bu qoraqalpoqcha emas. To'g'risi: `Bul maqalada qaraqalpaq tiliniń sintaksislik ózgeshelikleri tallanǵan.` [T]

## E. Asl v1 skilldagi shubhali shakllar

- `tabiǵiy` — manbalarda `tábiyiy` (`tábiyiy tildi qayta islew`) va `tábiyat` uchraydi [T]. v2 da `tábiyiy` ishlatildi.
- `mańızlı` — manbalarda uchramadi; `áhmiyetli` tasdiqlangan.
- `irkilis belgi` (tinish belgisi) — manbalarda tasdiqlanmadi.
- `grammar_policy.md` da `bergen` + kirill `де` aralash yozilgan edi (skript topdi).

## F. Shubha bo'lsa

Agar so'zning qoraqalpoqcha shakli jadvalda yo'q bo'lsa va ishonching komil bo'lmasa: o'zbekcha so'zni qoraqalpoqcha qo'shimcha bilan "kiyintirma". So'zni ishlatib, `(tekshirish kerak)` deb belgila yoki foydalanuvchiga ayt.
