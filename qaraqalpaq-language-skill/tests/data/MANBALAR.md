# Test matnlarining manbalari

`togri_matn.txt` va `yangi_togri_matn.txt` — tekshiruv skriptining soxta xato bermasligini o'lchash uchun nashr qilingan manbalardan olingan qisqa gaplar (har manbadan 1–3 gap). Ular faqat tilshunoslik sinovi uchun ishlatiladi.

- Zenodo'dagi ilmiy maqolalar sarlavha va annotatsiyalari (Qoraqalpoq davlat universiteti mualliflari, 2024–2026): records 18189076, 19384707, 14632313, 14704308, 14617288, 14523178.
- Qaraqalpaqsha Wikipedia: "Atlıq", "Almasıq", "Ráwish".
- Qaraqalpaq tili, 11-klass ushın sabaqlıq. Nókis, «Bilim», 2018.
- Qaraqalpaq tili, 8-klass (M. Dáwletov, E. Dáwenov, D. Seydullaeva); 7-klass; Ana tili 3-klass.
- NDPI "Ámeliy qaraqalpaq tili" test materiallari (2023).
- M. Dáwletov, Sh. Abdinazimov. Qaraqalpaq tiliniń orfografiyalıq sózligi. Nókis, «Bilim», 2020 — so'zboshi. PDF nusxasi OCR qilingan, shuning uchun diakritika kirill mosligi bo'yicha tiklangan.

`xato_matn.txt` — ataylab xato yozilgan sinov matni. Uning 8-qatoridagi kirill aralash so'z v1 skilldan olingan haqiqiy xato.

Agar siz biror matn muallifi bo'lsangiz va uni bu yerdan olib tashlashni xohlasangiz, Issue oching.
